Como foi criado

Este portfólio também é uma demonstração técnica do projeto.

A aplicação nasceu como um gerenciador de tarefas e evoluiu para um produto completo: API REST, frontend Angular, autenticação, isolamento de tarefas por usuário, formulário público de mensagens, testes, Swagger, Nginx e execução com Docker.

01. Domínio

Modelagem da regra de tarefas

Entidades, value object de título, factory e casos de uso para manter a regra de negócio fora da controller.

02. API

Contrato REST e persistência

Spring Boot com domínio, casos de uso, repositórios, JPA, validações, tratamento global de erros e Swagger.

03. Segurança

Autenticação e isolamento

Cadastro, login, token assinado e proteção das rotas de tarefas por usuário autenticado.

04. Interface

Angular e experiência do usuário

Angular com componentes, signals, facade, services HTTP, tela pública de portfólio e área logada de tarefas.

05. Publicação

Docker, EC2 e GitHub Pages

Docker Compose com Nginx servindo o frontend, proxy `/api` para o backend e publicação estática do portfólio no GitHub Pages.
